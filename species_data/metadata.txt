about=Build dot maps of vascular plant observations from Artportalen, using the open WFS service of the SLU Artdatabanken Species Observation System, without needing to know APIs or filter languages. Search by species name, period, map extent or county, count the matches first, and add them as a temporary point layer coloured by year. No account or API key is needed. Covers Sweden only, vascular plants only, Artportalen data only; protected (sensitive) observations are not included, and personal data fields are never downloaded. The user interface is in English with a Swedish translation, and a text explaining the panel is in the README. This is an independent, community-developed plugin. It is not developed, owned or endorsed by SLU or SLU Artdatabanken. Data is retrieved from SLU Artdatabanken under their API terms.
